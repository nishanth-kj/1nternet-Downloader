# Development setup

This guide covers the supported local build paths. Use the commands from the repository root unless stated otherwise.

## Desktop application (Windows)

### Requirements

- Windows 10 or 11
- Visual Studio with the **Desktop development with C++** workload
- CMake 3.21 or newer
- Git
- vcpkg

Install vcpkg from https://github.com/microsoft/vcpkg and set `VCPKG_ROOT` to the vcpkg checkout directory. For example, in PowerShell:

```powershell
$env:VCPKG_ROOT = "C:\\tools\\vcpkg"
```

Set it permanently in Windows Environment Variables if you want to reuse it across terminals.

### Build Debug

Open a terminal where the Visual Studio C++ compiler is available:

```powershell
cd core
cmake --preset default
cmake --build --preset default
```

### Build Release

```powershell
cd core
cmake --preset release
cmake --build --preset release
```

Build output is placed in `core/build/`. The executable and runtime DLLs are generated by the selected Visual Studio configuration.

### Optional build helper

From the repository root:

```powershell
.\core\scripts\build.ps1
.\core\scripts\build.ps1 -Preset release
.\core\scripts\build.ps1 -Clean
```

The helper uses the same CMake presets as the commands above. It does not install Visual Studio or vcpkg for you.

### Clean generated files

From `core/`:

```powershell
Remove-Item build -Recurse -Force -ErrorAction SilentlyContinue
cmake --preset default
cmake --build --preset default
```

Do not delete the global vcpkg checkout when cleaning this project's build.

## Android application

Android builds require JDK 17, Android SDK, NDK 27.0.12077973, CMake 3.22.1, and vcpkg.

Set these environment variables:

- `VCPKG_ROOT`: vcpkg installation directory
- `ANDROID_NDK_HOME`: Android NDK 27.0.12077973 directory

Build the native curl dependency using the repository's Android overlay triplet:

```bash
"$VCPKG_ROOT/vcpkg" install curl:arm64-android --classic --overlay-triplets=android/vcpkg-triplets
```

Then build the APK:

```bash
cd android
./gradlew assembleDebug
```

For a release build, use `./gradlew assembleRelease`.

The Android Gradle configuration expects the native dependency to be available through vcpkg. The Android app currently builds for `arm64-v8a` only.

## Website

Requirements: Node.js 20 or newer.

```bash
cd site
npm ci
npm run dev
```

Create the static production export with:

```bash
npm run build
```

The generated site is written to `site/out/`.

## Browser extensions

No package installation or build step is required. Load the relevant browser directory as an unpacked extension from the browser's extension management page.

For desktop handoff, first register the protocol from PowerShell:

```powershell
.\core\scripts\register_protocol.ps1
```

## Troubleshooting

- **CMake cannot find vcpkg:** verify `VCPKG_ROOT` and that `$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake` exists.
- **CMake cannot find a package:** remove `core/build/` and configure again. Confirm the dependency is declared in `core/vcpkg.json`.
- **Android native build fails:** confirm JDK 17, NDK 27.0.12077973, CMake 3.22.1, and the Android vcpkg overlay triplet are being used.
- **Browser handoff does nothing:** install the desktop application and register `idr://`; confirm the extension is enabled.
