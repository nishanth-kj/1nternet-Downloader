# Security Policy

## Supported versions

Security fixes are targeted at the latest version on the default branch. Until versioned releases are published, no stable release channel is promised.

## Reporting a vulnerability

Please do not publish exploit details or sensitive download URLs in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the maintainer privately through the contact method listed on the GitHub profile and include steps to reproduce, affected platform, and impact.

Please allow time to investigate and prepare a fix before publicly disclosing a vulnerability.

## Scope

Reports involving unsafe URL handling, browser-download interception, path traversal, untrusted torrent metadata, TLS validation, corrupted or misleading download completion, and native memory/thread safety are especially relevant.

Do not include malware samples or private user data in public reports.
